# 跨切分重疊對 bootstrap 區間的影響：修正與量化

**日期**：2026-09-28
**起因**：論文 v2 的 §3.4 指出「不同切分的測試集重疊 113,076 筆；原跨切分獨立重抽未保留此相依性」。
**結論**：批評成立，已修正。修正後交互作用區間幾乎不變，原結論存活。

## 一、問題確認

重疊數字經獨立核對，與 v2 所述完全一致：

| 項目 | 數值 |
|---|---:|
| Random 測試集 | 566,108 |
| Temporal 測試集 | 566,106 |
| 兩者交集 | **113,076** |
| 佔各自測試集 | 19.97% |
| 聯集 | 1,019,138 |
| 交集佔聯集 | 11.10% |

19.97% 正是兩個各取 20% 的測試集在獨立抽取下的期望重疊（期望值 113,221），所以這個重疊是切分設計的必然結果，不是實作疏失。

**原實作的缺陷**：`src/bootstrap_ci.py` 舊版將兩種切分的重抽樣視為獨立，再相減求交互作用。
兩個測試集共用五分之一的列，此假設無正當理由，交互作用的變異數因而未納入 Cov 項。

## 二、修正方式

改為**在兩個測試集的聯集上做一次聯合重抽樣**：

- 對聯集的每一列取得重複次數；**共用的列在兩種切分中帶入相同的重複次數**，相依性因而保留。
- 抽樣單位仍是列，抽取次數為聯集列數，故各切分的有效測試規模期望值維持原值。
- 實作上，聯集中「真實類別 × 六個變體各自的預測」完全相同的列彼此可交換，
  1,019,138 列塌縮為 **365 個結果組合**，10,000 次重抽在數秒內完成。
- 不屬於某切分測試集的列，在該切分的統計量中以哨符標記並排除。

舊的獨立估計保留在輸出中（`kind = interaction_independent_superseded`），與新估計並列，以便查核修正幅度。

## 三、修正後的結果

### 移除 Port 的交互作用

| 重抽方式 | 點估計 | 95% CI | 標準誤 | 排除 0 |
|---|---:|---|---:|:--:|
| 獨立（舊，已停用） | −9.6953 pp | [−13.5028, −5.1602] | 0.0211 | 是 |
| **聯合（新）** | **−9.6953 pp** | **[−13.5546, −5.1463]** | 0.0214 | **是** |

### 移除 TCP window 的交互作用

| 重抽方式 | 點估計 | 95% CI | 排除 0 |
|---|---:|---|:--:|
| 獨立（舊） | −0.3953 pp | [−2.5927, +0.5769] | 否 |
| **聯合（新）** | −0.3953 pp | [−2.6830, +0.5805] | 否 |

### 為什麼影響這麼小

兩個消融差值在聯合重抽下的**實測相關係數為 −0.0058**（TCP window 組為 −0.0107），即幾乎不相關。
因此 Cov 項近乎為零，獨立假設雖無正當理由，數值後果可忽略：區間端點變動約 0.05 個百分點。

推測原因（未進一步驗證）：Macro F1 的消融差值主要由罕見類別驅動，而兩種切分的模型是在不同訓練集上各自訓練的，
在共用列上的對錯型態並不一致；共用列又只佔聯集的 11.10%。

## 四、這項修正**沒有**解決的問題

修正只處理「跨切分重疊」一項。下列限制依然成立，v2 §3.4 的其餘保留語句應維持：

1. **同場景流量的相依性**。抽樣單位仍是單一流量列，但同一攻擊場景的流量高度相關，
   有效樣本數遠低於列數，所有區間（含逐切分的邊際區間）因此偏窄。這是目前最大的未解限制。
2. **切分本身未重抽**。區間描述的是「固定這組切分下，測試樣本組成的變異」，不含重新切分的變異。
3. **稀有類別**。Heartbleed（2 筆）等類別在重抽樣中可能整類缺席，Macro 平均的處理方式需明確交代。
4. **跨場景／部署推論**。以上皆不支持。

## 五、對論文的建議

v2 因應此問題，將交互作用的信賴區間與「排除 0」的宣稱移出摘要。修正後的數據顯示這比必要程度更保守：
**在正確的聯合重抽下，該區間仍排除 0**。

因此可考慮把交互作用區間放回，但改以正確的方法描述，例如：

> 交互作用為 −9.70 個百分點（聯合重抽樣 95% CI [−13.55, −5.15]）。此區間以兩測試集聯集的逐列重抽樣估得，
> 已納入兩者 113,076 筆重疊所造成的相依，但未涵蓋同場景流量的相關，亦不支持跨場景或部署推論。

是否放回由論文主筆決定；本文件只負責提供修正後的正確數字與其適用範圍。
